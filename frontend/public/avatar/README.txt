HOW TO SWAP IN YOUR CUSTOM 3D AVATAR:
=========================================
1. Export your humanoid model as a .glb or .vrm file with facial blendshapes (e.g. mouthOpen, jawOpen, blink).
2. Rename your model to:
   awaaz.glb (or awaaz.vrm)
3. Place it directly into this folder:
   /public/avatar/awaaz.glb
4. The AvatarCanvas component will detect this file and automatically render your custom rigged avatar instead of the procedural cybernetic hologram bust.
